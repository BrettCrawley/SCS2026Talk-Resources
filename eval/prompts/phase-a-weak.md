# Weak skill prompt

Deliberately a single pass straight to a threat model. No chained skills, no use
cases, no abuse cases, no gap analysis, no architecture review. This is what most
people have, and the contrast is the teaching point.

Do not add the other skills to this prompt. If you do, the run is not measuring
what it claims to measure.

---

/threat-model-weak Produce a threat model of this system.

All input material is in ./input. Read every file, including diagrams. Where a
repository is present, use it as supporting material.

Write the threat model into ./output as a markdown file.
